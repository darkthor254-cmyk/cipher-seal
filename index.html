What's on board

◆

AES-256-GCM

Authenticated encryption via the browser's native Web Crypto API — the wrong key fails loudly, it never returns garbage text.

◆

PBKDF2 key stretching

Your passphrase is run through 150,000 rounds of PBKDF2 with a fresh random salt every time, not used as a raw key.

◆

Zero server contact

No backend, no database, no logs. The plaintext and the key never leave this browser tab.

◆

QR handoff

Turn cipher text into a QR code for handing off a message in person, no copy-paste needed.

◆

Key generator

Not confident in your own passphrase? Generate a strong random one with a tap.

◆

.txt in and out

Download cipher text as a file, or upload one straight into the decrypt box.

How a message travels

01 — sender

Write the message and choose a secret key.

02 — this page

Derives a key from the passphrase and encrypts with AES-256-GCM.

03 — handoff

Cipher text travels over WhatsApp, email, or a QR code — the key travels another way.

04 — receiver

Pastes the cipher text, enters the same key, reads the message.
